Overview

VaultSeek is a Windows desktop application that helps you organize, identify, and complete a personal music library. It watches an Incoming folder, fingerprints and tags audio, moves approved files into Library, syncs artwork, and can search external sources for missing tracks or better quality versions.

Typical workflow:

  1. Drop new files into Incoming (or download via acquisition).
  2. VaultSeek scans, fingerprints, and identifies metadata.
  3. Uncertain items appear in Review; the rest auto-approve or wait per your threshold.
  4. Approved files are organized into Library (artist/album folders).
  5. Use Find music to detect gaps, then Wishlist to search and download.

First run

On first launch, the Setup wizard (Help → Setup wizard) walks you through:

  • Library name and four zone folders (Incoming, Staging, Library, Archive)
  • Optional Nicotine+ connection settings
  • Optional Discogs and AcoustID tokens
  • Quality preferences for acquisition

You can reopen the wizard anytime from the menu. After setup, use File → Scan Incoming or Settings → Scan incoming now to process files already in Incoming.

Library zones

Each library uses four folders on disk (configured in Settings → Library):

ZonePurpose
IncomingDrop zone for new audio. Watched when enabled. Files stay here through identify/review until approved.
StagingOptional legacy hold folder. Most workflows use Incoming → Library directly.
LibraryCanonical organized collection (artist/album layout after organize).
ArchiveDuplicates and rejected files.

Watch incoming folder — when checked, new files in Incoming trigger a scan automatically. Auto-approve threshold (0–1) — metadata confidence at or above this value skips Review.

Dashboard

Shows library health: track counts by zone, acquisition pipeline stages, recent failures, and a Getting started checklist for new installs. Click attention items to jump to Review, Wishlist, or Logs as appropriate.

Library (Files)

Browse every track in the active library with zone, confidence, and quality indicators. Color coding reflects your quality preset (green = meets target, orange = below).

  • Right-click — Reveal in Explorer, Find missing songs, Find quality upgrades, Open Find music
  • Column headers — Click to sort; drag column edges to resize

Artists & Albums

Artists

List artists with album and track counts. Select an artist to see their tracks.

Albums

Browse albums with health status (complete / missing tracks / quality issues). Selecting an album shows cover art and a track list compared to MusicBrainz when available.

Album right-click actions:

  • Find missing songs (this album) — fast scan for gaps on one album only
  • Find missing songs (whole library) — full library gap scan
  • Queue this album for download — add a whole-album Wishlist job

The Wanted panel lists parked albums (from Discogs or manual picks) before you promote them to active download jobs.

Find music

Two tabs:

Library gaps

  • Find missing songs — compares your library to MusicBrainz tracklists and missing files on disk; creates Wishlist jobs per missing track
  • Find quality upgrades — finds tracks below your quality preset; creates upgrade jobs

Results appear on the status line (no popup). Open Wishlist to acquire.

Discogs browse

Search Discogs for releases, preview tracklists, and add selections to Wanted or Wishlist. Requires a Discogs token in Settings (optional but recommended).

Wishlist (Acquisition page)

Central place for acquisition jobs — each job represents something you want to find and download (missing track, album, or quality upgrade).

ActionWhat it does
Auto-acquire selectedSearch providers, score results, download if above threshold
Scan for missingRun a full-library missing-track scan from here
Show wantedInclude parked Wanted-shelf jobs in the table

Job states progress through: Created → Queued → Searching → Scoring → Downloading → Verifying → Importing → Completed (or No results / Waiting for user).

Review queue

Human approval for uncertain metadata, duplicates, or failed acquisitions. Ctrl+Enter approve, Ctrl+Shift+R reject. Approved items continue through organize; rejected items may move to Archive.

Jobs & Activity

Jobs

Background pipeline tasks: scan, hash, fingerprint, identify, organize, artwork, media-server sync. Filter by library and status.

Activity

Recent acquisition and import events — useful when debugging search or download issues.

Reports & Logs

Reports — generated library summaries on disk. Logs — live view of vaultseek.log and debug.log. Open log folder via File → Open Log Folder.

Nicotine+ (Soulseek)

Configured here; enable the provider and set transport:

  • HTTP — talks to the api-nicotine-plus plugin (recommended). Default API port 12339.
  • Socket — NDJSON companion proxy on port 22024 (advanced).

Use Test Nicotine+ connection before saving. Set conservative search rate limits to avoid Soulseek flood bans (~30 minutes).

Application

  • Log level — DEBUG for troubleshooting
  • Theme — dark or light
  • Discogs token — metadata and covers from Discogs
  • AcoustID — up to 3 API keys + optional HTTP proxies for fingerprint throughput
  • Fingerprinting — fingerprint every file, or sample N songs per album folder (faster)

Media servers

Configure Navidrome, Jellyfin, Plex, Emby, Subsonic, Ampache, Koel, Funkwhale, or Lyrion. VaultSeek can trigger library scans after imports when configured.

Organize rules

Custom path templates and rules for how files are named and placed in Library (see Rules section at bottom of Settings).

Plugins (detailed)

All plugins are opt-in and disabled by default. Save settings after changes; download providers reconnect immediately.

Similar music (Last.fm)

Suggests albums by artists similar to those in your library. Free API key from last.fm/api. Suggestions appear on the Wishlist as parked entries — they do not download automatically.

Spotify playlist sync

Mirrors albums from public Spotify playlists into your Wishlist. Create an app at developer.spotify.com/dashboard, enable Web API, and paste the Client ID and Client secret here.

VaultSeek uses Spotify’s Client Credentials flow (app token, not user login). Only public playlists are supported. Spotify’s developer rules may require Spotify Premium on the account that owns the developer app for Web API access. A dummy redirect URI (e.g. http://127.0.0.1:8888/callback) is often required when creating the app even though VaultSeek does not use OAuth redirects.

Enable Prowlarr plus at least one download client. Use the Test buttons to verify connectivity.

How acquisition works

  1. Search — providers (Nicotine+, Prowlarr, …) query external sources
  2. Score — results ranked by artist/album/title/format match
  3. Download — best hit sent to qBittorrent, SABnzbd, or Nicotine+
  4. Verify — files checked before import
  5. Import — audio copied into Incoming, then normal scan/organize pipeline

For missing-track jobs, VaultSeek searches for the whole album first; if no acceptable album pack is found, it falls back to per-track search at the same quality settings.

Connecting Nicotine+

  1. Install and run Nicotine+ on the same PC.
  2. Log into Soulseek inside Nicotine+ and stay connected.
  3. Install api-nicotine-plus (HTTP API plugin) if using HTTP transport.
  4. In VaultSeek Settings → Acquisition: enable Nicotine+, set transport to HTTP, port 12339, optional API token.
  5. Click Test Nicotine+ connection, then Save preferences.

Connecting Prowlarr, qBittorrent, and SABnzbd

Ports (important)

AppDefault URL
Prowlarrhttp://127.0.0.1:9696
SABnzbdhttp://127.0.0.1:8080
qBittorrenthttp://127.0.0.1:8081 (avoid sharing 8080 with SABnzbd)

Prowlarr

  1. Add audio indexers in Prowlarr (Torznab / Newznab).
  2. Copy API key from Prowlarr → Settings → General.
  3. In VaultSeek Plugins: enable Prowlarr, paste URL + key, set minimum seeders for torrents.

qBittorrent

  1. Enable Web UI in qBittorrent (Tools → Options → Web UI).
  2. Set port to 8081 if SABnzbd uses 8080.
  3. In Plugins: enable qBittorrent, enter URL, username, password, optional category vaultseek.

SABnzbd

  1. Configure your Usenet server in SABnzbd.
  2. Copy API key from SABnzbd → Config → General.
  3. In Plugins: enable SABnzbd, paste URL + key, optional category.
Saving Settings no longer clears Plugins download credentials. If searches fail after changing Settings, open Plugins and confirm Prowlarr/qBit/SAB are still enabled, then Save.

Last.fm & Spotify tips

  • Run Find recommendations now on the Plugins page after saving credentials.
  • New suggestions are de-duplicated against albums you already own.
  • Promote Wishlist items when you are ready to download — recommenders never download by themselves.

Data & logs

VaultSeek stores configuration and the database under:

%APPDATA%\VaultSeek\

  • config.json — settings (includes API keys; never share this file)
  • vaultseek.db — SQLite catalog
  • logs\vaultseek.log — main log
  • logs\debug.log — verbose debug log
  • crashes\ — crash dumps if any

Only one VaultSeek instance should run at a time (database lock).
